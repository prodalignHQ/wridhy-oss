⚙️ Operating Modes

Three ways to use MoMoney — from fully private to full cloud sync

Why Modes?

Different users have fundamentally different comfort levels with cloud data storage. MoMoney solves this by offering three distinct operating modes — users can choose the one that fits their privacy preferences and usage pattern, and can migrate between them at any time.

Mode 1 — Session Mode

🔐

Session Mode (Default for hosted)

Financial data lives only in the browser's memory or local storage. Nothing is sent to or stored on the server. When the session ends, the data is gone — unless the user exports it.

  • Transactions exist in browser memory only
  • Backend database stores no financial records
  • Insights are computed entirely on-device
  • Data disappears when the session ends (without export)
Maximum privacy Zero server storage Export: SQLite / CSV / JSON

Mode 2 — Cloud Persistence

☁️

Cloud Persistence (Explicit opt-in)

Users explicitly grant permission to store financial data on the server. This unlocks cross-device access, long-term analytics, and persistent invoices.

  • Access your data from any device
  • Persistent analytics and historical insights
  • Persistent invoice drafts and generated invoices
  • Automatic backups
  • Users can disable persistence or delete all stored data at any time
Cross-device Long-term history Requires explicit consent
Consent requirement: Users must explicitly approve: "Allow this platform to securely store my financial data." This is not set by default and must be a conscious action.

Mode 3 — Local SQLite Mode

🗄️

Local SQLite Mode

Users run MoMoney against a local SQLite database file — either imported from a previous session export or created fresh. This enables fully offline operation with all features available.

  • Fully offline — no internet required after initial load
  • Statement uploads, categorization, invoices, analytics all work
  • Net worth tracking available
  • Import/export SQLite file anytime
  • Download backups of the local file
Fully offline No cloud dependency SQLite schema mirrors cloud

Data Migration Between Modes

Users are never locked into a mode. They can move their data between modes freely.
