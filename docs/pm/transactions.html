💳 Transactions

The central view for managing, categorizing, and attributing all imported transactions

Overview

The Transactions Dashboard is the main workspace in MoMoney. After importing statements, all extracted transactions appear here. Users can search, filter, bulk-edit, assign owners, and adjust categories. This view is the foundation for all downstream analytics and invoices.

What Users Can Do

🔍

Search & Filter

Filter transactions by date range, account, category, merchant, owner, or debit/credit type. Full-text search on descriptions.

🏷️

Edit Categories

Change the category of individual transactions. Can also bulk-reassign a category to multiple selected rows at once.

🏪

Edit Merchants

Override the auto-detected merchant name. Useful when the normalized name isn't matching the user's mental model.

👤

Assign Owners

Tag a transaction to one or more household members (owners). Can split the amount across multiple owners by percentage.

✏️

Add Comments

Each transaction supports a free-text comment field for personal notes (e.g., "Annual subscription for tool X").

☑️

Bulk Operations

Select multiple transactions and bulk-assign a category or owner in a single action — saves time when cleaning up imported data.

Owner Assignment & Splitting

Every transaction can be attributed to one or more "owners" — people within the user's household or expense-sharing group. Owners can each carry a percentage share of the transaction amount.

Example: Equal Split

A ₹4,000 dinner transaction split between Alex and Sam:

  • Alex → 50% → ₹2,000
  • Sam → 50% → ₹2,000

Owner Types

  • Person — an individual (e.g., "Rohan", "Priya")
  • Shared — a shared/joint expense
  • Household — attributed to the whole household

A default "Self" owner is created when you sign up.

Invoice Impact: Owner splits flow through to invoice analysis. When generating a monthly invoice, the "who spent how much" breakdown respects the split percentages assigned here.

Merchant Normalization

Bank transaction descriptions are often messy and inconsistent. MoMoney normalizes them before display.

Raw Bank DescriptionNormalized Merchant
AMZN MKTP IN 7X3K4DAmazon
Amazon MarketplaceAmazon
AMAZON PAY INDIA PVTAmazon
ZOMATO-ORDER 8834Zomato
UPI/SWIGGY/123456Swiggy

Normalization is driven by a system merchant dictionary and can be extended by users. It improves categorization accuracy since rules match on merchants, not raw descriptions.
