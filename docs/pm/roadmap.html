🗺️ Roadmap

What's built, what's being built, and what comes next

Current Status

MoMoney is being built in distinct phases. The project has completed Phase 0 (foundation) and is actively in progress on core features.

Phase 0 — Foundation ✅ Complete

What was built

  • Turborepo monorepo setup with pnpm workspaces
  • Drizzle ORM schema definition (all core tables)
  • Shared TypeScript type definitions (Zod models)
  • Next.js 16 app shell with dark mode and Shadcn UI components
  • Hono.js API health check and route stubs
  • Docker Compose postgres setup for local dev

Implemented Features

These are features that exist in the codebase based on current routes, pages, and API endpoints:

Authentication

Signup, login, logout, email verification via Better Auth. Protected routes with session middleware.

Financial Accounts

Create and manage bank accounts, credit cards, wallets, and investment accounts.

Statement Upload & Parsing

Upload ICICI bank statements in PDF, CSV, and XLS formats. Parse and preview transactions before import. Deduplication on import.

Transaction Dashboard

Full transaction table with filtering, search, category editing, merchant editing, owner assignment, bulk operations, and comment fields.

Categorization Rules Engine

Create and manage rules (match on merchant/description/amount). System and user rules with priority ordering.

Invoices (Drafts + Generation)

Create invoice drafts from tagged statements, generate permanent snapshots, view analysis (per-owner and per-category spending breakdowns).

Net Worth Tracking

Log assets and liabilities, save monthly snapshots, draft support. Asset types include mutual funds, stocks, FDs, real estate, crypto, and more.

Owners Management

Create owners (people and household groups), assign to transactions with percentage splits.

Merchants

System and user merchant dictionary. Raw pattern matching to normalized merchant names.
