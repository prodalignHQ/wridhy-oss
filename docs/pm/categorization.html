🏷️ Categorization

How MoMoney automatically (and accurately) classifies every transaction

How Categorization Works

MoMoney uses a layered approach to categorize transactions automatically. Categories come pre-configured at the system level and can be supplemented by user-defined rules. When a user manually overrides a category, the system can also create a new rule to apply that override automatically in the future.

Default Categories

🍕 Food & Dining 🛒 Groceries 🛍️ Shopping ✈️ Travel 🚗 Transport 📦 Subscriptions 💡 Utilities 🏥 Healthcare 🎬 Entertainment 🏠 Rent 📈 Investment 🔄 Transfers 💰 Income 🎓 Education

System categories are pre-seeded and available to all users. Users can also create their own custom categories.

Rules Engine

Users can define automation rules that apply categories based on field matches. Rules have a priority — user rules take precedence over system rules.

Rule ComponentOptionsExample
Match Field merchant, description, amount merchant
Match Type contains, equals, regex, gt, lt contains
Match Value Any string or number "uber"
Assigned Category Any category Transport
Priority 1–999 (user), 1000–4999 (system) 100
Example rules:
If merchant contains "uber" → Transport
If description contains "salary" → Income
If merchant equals "Swiggy" → Food & Dining

Manual Overrides

Users can always manually change the category for any transaction directly from the transaction list. When they override a category, they can optionally create a new rule from that action — so the same merchant is auto-categorized correctly in the future.

Example: Fixing an Amazon Transaction

  • Amazon auto-categorized as "Shopping"
  • User changes it to "Groceries" (for Amazon Fresh orders)
  • User creates a rule: if merchant = "Amazon" and description contains "Fresh" → Groceries
  • Future Amazon Fresh transactions categorized correctly automatically
